# Project Overview

Програма реалізує побудову та обробку 2D трикутної сітки для маски/контуру з фокусом на `LinearTriangle` і AFM-мешинг.  
Призначення: підготовка коректної трикутної геометрії, перевірка її валідності, розрахунок базисних функцій і подальше використання в обчисленнях/візуалізації.

# Implemented Features

- `LinearTriangle` з:
  - `triangle_id` / `triangle_number`;
  - `node_ids` / `node_numbers`;
  - координатами 3 вузлів;
  - площею трикутника.
- Обчислення площі трикутника (signed/unsigned).
- Перевірка орієнтації та авто-виправлення від’ємного обходу.
- Обробка вироджених трикутників (`\Delta = 0` -> помилка).
- Лінійні базисні функції `\varphi_i, \varphi_j, \varphi_k`.
- Глобальна наскрізна нумерація вузлів/трикутників на рівні сітки.
- Валідація геометрії та вхідних даних.
- Unit tests для `LinearTriangle` і інтеграційних сценаріїв.

# Supported Modes

- Графічний режим редагування маски (Pen/Eraser/Fill/Shape tools).
- Режими триангуляції: `Fast`, `Balanced`, `Accurate`, `Custom`.
- Режим побудови/перевірки `LinearTriangle` у доменному шарі.
- Тестовий режим (unit/integration tests).

# Input Data

- Координати вузлів: 3 точки `Point(x, y)`.
- Номери вузлів: 3 додатні цілі `node_ids`.
- Номер трикутника: додатне ціле `triangle_id`.

Формат для `LinearTriangle`:
- `triangle_number: int`
- `node_coordinates: tuple[Point, Point, Point]`
- `node_numbers: tuple[int, int, int]`

# Applied Algorithms

## Triangle Area

\[
\Delta =
\frac{1}{2}
\begin{vmatrix}
1 & x_i & y_i \\
1 & x_j & y_j \\
1 & x_k & y_k
\end{vmatrix}
\]

Використовується для:
- обчислення площі;
- визначення орієнтації (знак \(\Delta\));
- перевірки виродженості.

## Linear Basis Functions

\[
\varphi(x,y)=\alpha+\beta x+\gamma y
\]

Використовується для:
- локальної апроксимації всередині лінійного трикутного елемента;
- інтерполяції вузлових значень.

## AFM Meshing (Advancing Front Method)

Використовується для:
- генерації трикутної сітки з контуру/маски;
- побудови робочої геометрії для подальшого аналізу.

## Laplacian Smoothing

Використовується для:
- покращення якості трикутників після первинної генерації сітки.

## Ramer-Douglas-Peucker (RDP)

Використовується для:
- спрощення контуру перед триангуляцією (`epsilon`).

## Ear Clipping Triangulation

Використовується для:
- fallback-триангуляції, коли фронт AFM не може просунутись.

## Ray Casting Point-in-Polygon Test

Використовується для:
- перевірки належності точки полігону.

## Segment Intersection Test (orientation-based)

Використовується для:
- перевірки перетинів ребер і запобігання невалідним з'єднанням.

# Validation

- Рівно 3 координати вузлів.
- Рівно 3 `node_ids`.
- `node_ids` — додатні цілі та унікальні в межах трикутника.
- `triangle_id` — додатне ціле.
- Координати вузлів унікальні.
- Координати є finite-значеннями.
- Трикутник не вироджений.
- Площа додатна після перевпорядкування (за потреби).

# Testing

- Реалізовано unit tests.
- Перевіряються:
  - створення/валідація `LinearTriangle`;
  - площа, орієнтація, виродженість;
  - базисні функції у вершинах і умова \(\varphi_i+\varphi_j+\varphi_k=1\);
  - сценарії глобальної нумерації.
- Поточний тестовий прогін — успішний (`OK`).
