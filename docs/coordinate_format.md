# Формат JSON для імпорту координат

Стандартний формат файлу координат у проекті `afm_mesher`:

```json
{
  "outer_boundary": [
    [100.0, 200.0],
    [300.0, 200.0],
    [300.0, 400.0],
    [100.0, 400.0],
    [100.0, 200.0]
  ],
  "inclusions": [
    {
      "vertices": [
        [150.0, 250.0],
        [250.0, 250.0],
        [250.0, 350.0],
        [150.0, 350.0],
        [150.0, 250.0]
      ],
      "type": "ignore"
    }
  ],
  "cuts": [
    [
      [120.0, 210.0],
      [280.0, 390.0]
    ]
  ]
}
```

## Правила схеми

- `outer_boundary` — обов'язковий список пар `[x, y]`
- `inclusions` — опційний список об'єктів:
  - `vertices` — список пар `[x, y]`
  - `type` — `"ignore"` або `"merge"`
- `cuts` — опційний список поліліній
- координати можуть бути `int` або `float`

## Семантика

- `outer_boundary` — зовнішній контур області
- `inclusions` — внутрішні контури включень
- `cuts` — відкриті контури розрізів

## Конвертація у внутрішній формат проекту

Внутрішній формат canvas:

```python
list[list[tuple[float, float]]]
```

- `outer_boundary` і `inclusions` конвертуються у замкнені контури
- `cuts` конвертуються у відкриті контури без автоматичного замикання
